# இனம் – தமிழ் அலுவல் உதவி

**Inam – Tamil Official Assistant**

அலுவலகப் பயன்பாட்டிற்கான தமிழ் உரைத் திருத்தம், மொழிநடை மேம்பாடு மற்றும் அலுவல் ஆவண வரைவு உருவாக்க உதவும் திறந்த மூல இணையச் செயலி.

## முதல் பதிப்பின் வசதிகள்
- தமிழ் உரையை உள்ளிடுதல் மற்றும் திருத்துதல்
- தொடக்கநிலை விதிமுறை அடிப்படையிலான சொற்றொடர் திருத்தம்
- விருப்பத்தேர்வாக AI மொழிநடை மேம்பாடு
- அலுவல் கடிதம், அலுவலகக் குறிப்பு, அறிக்கை, சுற்றறிக்கை, குறிப்பாணை, அரசாணை வரைவு, கூட்ட நடவடிக்கைக் குறிப்புகள், நினைவூட்டல் கடிதம் ஆகியவற்றுக்கான வரைவு வடிவங்கள்
- DOCX, TXT, HTML பதிவிறக்கம் (HTML-ஐ உலாவியில் திறந்து PDF ஆக அச்சிடலாம்)

## கணினியில் இயக்குதல்
1. Python 3.10 அல்லது அதற்கு மேற்பட்ட பதிப்பை நிறுவவும்.
2. இந்தக் கோப்புறை உள்ள Terminal / PowerShell திறக்கவும்.
3. மெய்நிகர் சூழலை உருவாக்கவும்:
   ```bash
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
4. தேவையான தொகுப்புகளை நிறுவவும்:
   ```bash
   pip install -r requirements.txt
   ```
5. செயலியை இயக்கவும்:
   ```bash
   streamlit run app.py
   ```

## AI வசதி
AI வசதியைப் பயன்படுத்த `OPENAI_API_KEY` சூழல் மாறியை அமைக்க வேண்டும். உண்மையான API விசையை GitHub-இல் பதிவேற்ற வேண்டாம். AI சேவைக்கு உரை அனுப்பப்படும்; எனவே ரகசிய அல்லது தனிப்பட்ட அரசு ஆவணங்களை உரிய அனுமதி மற்றும் பாதுகாப்பு ஆய்வின்றி அனுப்ப வேண்டாம்.

## முக்கிய வரம்புகள்
- முதல் பதிப்பின் விதிமுறைத் திருத்தங்கள் சில எடுத்துக்காட்டு விதிகள் மட்டுமே; முழுமையான தமிழ் இலக்கணச் சரிபார்ப்பு அல்ல.
- AI பரிந்துரைகளில் தவறுகள் இருக்கலாம். மனிதர் சரிபார்ப்பு அவசியம்.
- பெயர்கள், தேதிகள், தொகைகள், கோப்பு எண்கள், சட்டக் குறிப்புகள் மற்றும் அரசாணை விவரங்களை மூல ஆவணங்களுடன் சரிபார்க்க வேண்டும்.
- அரசாணை வரைவு ஒரு தொடக்க வடிவம் மட்டுமே; அதிகாரப்பூர்வ ஆணையாகாது.
- DOCX கோப்பின் தமிழ் எழுத்துருக் காட்சி, பயனரின் கணினியில் நிறுவப்பட்டுள்ள எழுத்துருவைப் பொறுத்தது.

## தனியுரிமை
இந்த மாதிரி செயலி உள்ளீட்டு உரையைத் தனிப்பட்ட தரவுத்தளத்தில் சேமிப்பதில்லை. இருப்பினும் ஹோஸ்டிங் சேவை, சேவையகப் பதிவுகள் மற்றும் இணைக்கப்பட்ட AI சேவை உரையைச் செயலாக்கக்கூடும். உணர்வுபூர்வமான ஆவணங்களுக்கு அங்கீகரிக்கப்பட்ட, பாதுகாப்பான உள்ளக அல்லது அரசு வழங்கும் சேவையகத்தைப் பயன்படுத்த வேண்டும்.

## உரிமம்
இந்தக் களஞ்சியத்தில் புதிதாக உருவாக்கப்பட்ட நிரல் குறியீட்டிற்கு மட்டும் MIT உரிமம் பொருந்தும். வெளிப்புற எழுத்துருக்கள், தரவுத்தொகுப்புகள், அரசு ஆவணங்கள் மற்றும் மூன்றாம் தரப்பு மென்பொருட்களுக்கு அவற்றின் தனிப்பட்ட உரிம நிபந்தனைகளே பொருந்தும்.
