# இனம் – தமிழ் அலுவல் உதவி (Patch 2.1)

இந்த ZIP-இல் புதுப்பிக்கப்பட்ட கோப்புகள் மட்டுமே உள்ளன.

## கோப்புகளை மாற்ற வேண்டிய இடங்கள்
- `app.py` → திட்டத்தின் முதன்மை `app.py`
- `inam/ai_assistant.py` → `inam/ai_assistant.py`
- `inam/exporters.py` → `inam/exporters.py`
- `requirements.txt` → திட்டத்தின் `requirements.txt`

மற்ற `inam` கோப்புகள் (குறிப்பாக `corrector.py`, `documents.py`) தற்போதைய திட்டத்தில் இருப்பதைப் போலவே வைத்திருக்கவும்.

## நிறுவல்
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Gemini API அமைத்தல்
`.streamlit/secrets.toml` கோப்பை உருவாக்கி:
```toml
GEMINI_API_KEY = "உங்கள்_Gemini_API_Key"
GEMINI_MODEL = "gemini-2.5-flash"
```

API Key-ஐ GitHub-இல் அல்லது நிரல் கோப்பில் நேரடியாகச் சேர்க்க வேண்டாம்.

## செயல்பாடு
1. அலுவல் ஆவணம் தாவலைத் திறக்கவும்.
2. ஆவண வகையைத் தேர்ந்தெடுக்கவும்.
3. மாதிரி DOCX / உரை PDF / TXT கோப்பைப் பதிவேற்றவும்.
4. புதிய ஆவணத்திற்கான விவரங்களை உள்ளிடவும்.
5. “பதிவேற்றிய மாதிரியைப் பின்பற்றி Gemini AI மூலம் உருவாக்கு” பொத்தானை அழுத்தவும்.
6. உருவான வரைவைக் சரிபார்த்து Word/TXT/HTML ஆகப் பதிவிறக்கவும்.
