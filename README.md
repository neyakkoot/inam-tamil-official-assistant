# இனம் – தமிழ் அலுவல் உதவி (Version 2.0)

தமிழ் உரைத் திருத்தம், அலுவல் மொழிநடை மாற்றம், அலுவல் ஆவண உருவாக்கம் மற்றும் பதிவிறக்கம் ஆகியவற்றுக்கான Streamlit செயலி.

## முக்கிய அம்சங்கள்

### API இல்லாமல் இயங்கும் இலவச வசதிகள்
- தமிழ் சொற்றொடர் / சொல் இணைப்பு விதிமுறைத் திருத்தம்
- தேவையற்ற இடைவெளி சீரமைப்பு
- அலுவல் மொழிநடை விதிமுறை மாற்றம்
- எட்டு வகையான அலுவல் ஆவண வரைவு உருவாக்கம்
- Word (.docx), TXT, HTML பதிவிறக்கம்

### விருப்பத்தேர்வு AI
- Gemini API Key அமைக்கப்பட்டால் மட்டும் AI மேம்பாடு செயல்படும்.
- API Key இல்லாவிட்டாலும் அடிப்படை வசதிகள் தொடர்ந்து இயங்கும்.
- Gemini API இலவசத் திட்டத்திற்கும் மாதிரி/பயன்பாட்டு வரம்புகள் பொருந்தும்.

## உள்ளூரில் இயக்குதல்

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

தொகுப்புகளை நிறுவ:
```bash
pip install -r requirements.txt
```

செயலியை இயக்க:
```bash
streamlit run app.py
```

## Gemini API விருப்ப அமைப்பு

Google AI Studio-வில் API Key உருவாக்கவும்:
https://aistudio.google.com/api-keys

உள்ளூரில் `.streamlit/secrets.toml` என்ற கோப்பை உருவாக்கி:

```toml
GEMINI_API_KEY = "உங்கள்-Gemini-API-Key"
GEMINI_MODEL = "gemini-3.8-flash"
```

இந்த `secrets.toml` கோப்பை GitHub-ல் பதிவேற்ற வேண்டாம்.

## Streamlit Community Cloud

1. GitHub-ல் இந்தத் திட்டத்தைப் புதுப்பிக்கவும்.
2. Streamlit Community Cloud-இல் செயலியின் Settings திறக்கவும்.
3. Secrets பகுதியில் கீழ்க்கண்டதைச் சேர்க்கவும் (AI வசதி வேண்டுமெனில் மட்டும்):

```toml
GEMINI_API_KEY = "உங்கள்-Gemini-API-Key"
GEMINI_MODEL = "gemini-3.8-flash"
```

4. Save செய்து app-ஐ reboot செய்யவும்.
5. AI Key சேர்க்காமல் விட்டாலும் அடிப்படை வசதிகள் இயங்கும்.

## பாதுகாப்பு, வரம்புகள்

- API Key-ஐ `app.py`, GitHub அல்லது பொதுவான README கோப்பில் எழுத வேண்டாம்.
- Streamlit Secrets அல்லது சூழல் மாறி வழியாக மட்டுமே அமைக்கவும்.
- Gemini இலவசத் திட்டத்தின் பயன்பாட்டு வரம்புகள் Google-ஆல் மாற்றப்படலாம்.
- இலவச API திட்டத்தில் அனுப்பப்படும் உள்ளடக்கங்கள் சேவை வழங்குநரின் தரவுக் கொள்கைக்கு உட்பட்டவை. ரகசிய அரசு ஆவணங்கள் அல்லது தனிப்பட்ட தகவல்களை AI-க்கு அனுப்ப வேண்டாம்.
- விதிமுறை அடிப்படையிலான திருத்தம் முழுமையான தமிழ் இலக்கணச் சரிபார்ப்பி அல்ல.
- அனைத்து அலுவல் ஆவணங்களும் தொடக்க வரைவு மட்டுமே; வெளியிடுவதற்கு முன் மனிதர் சரிபார்க்க வேண்டும்.
