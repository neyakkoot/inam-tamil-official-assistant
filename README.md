
# Inam – Tamil Official Assistant

## English Version

### About the Project

Inam – Tamil Official Assistant is an open-source web application designed to support Tamil language correction, official language refinement and the preparation of Tamil official documents.

The project aims to help government employees, teachers, researchers and the general public prepare clear and grammatically improved Tamil official documents.

### Features – Version 1.1

- Basic Tamil phrase and spacing correction.
- Tamil official language refinement.
- Explanation of suggested corrections.
- Official document drafting.
- Word (DOCX), TXT and HTML export.
- Optional AI-powered language improvement.

### Supported Document Types

1. Official Letter
2. Office Note
3. Report
4. Circular
5. Memorandum
6. Government Order Draft
7. Meeting Minutes
8. Reminder Letter

### Technology Stack

- Python
- Streamlit
- Python-docx
- OpenAI API (Optional)

### Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Limitations

This is an early-stage prototype, not a complete Tamil grammar checker.

Context-sensitive Tamil letters such as ண/ந/ன, ல/ள/ழ and ர/ற are not automatically modified.

All official documents must be verified by authorized personnel before official use.

### Privacy

Do not submit confidential government documents to external AI services without proper authorization.
